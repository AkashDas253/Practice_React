
# Calculator App

This project is a simple calculator tool that allows users to perform basic arithmetic operations: addition, subtraction, multiplication, and division. It is designed to be easy to use and accessible on any device.

## Features

- Add, subtract, multiply, and divide numbers
- Clear/reset functionality
- Real-time result display
- Keyboard and button input support
- Responsive layout for desktop and mobile

## How to Use

1. Enter numbers using the on-screen buttons or your keyboard.
2. Select the desired operation (+, -, ×, ÷).
3. Press `=` to view the result.
4. Use `C` or `Clear` to reset the calculator.

## Project Structure

- `src/` — Source code for the calculator logic and UI
- `public/` — Static assets
- `README.md` — Project documentation

## Getting Started

Clone the repository and open the project folder. No special setup is required if you use the provided HTML/JS/CSS files. For advanced usage or customization, refer to the source code and documentation.
