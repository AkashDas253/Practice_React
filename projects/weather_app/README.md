
# Weather App

This is a React-based Weather App that allows users to search for current weather information by city. It fetches live weather data from a public API and displays temperature, humidity, and weather conditions.

## Getting Started

To run this project locally:

1. Open a terminal in this directory.
2. Run `npm install` to install dependencies.
3. Run `npm start` to launch the development server.
4. Visit [http://localhost:3000](http://localhost:3000) in your browser.

## Features
- Search weather by city name
- View temperature, humidity, and weather conditions
- Responsive design for desktop and mobile

## Scripts

### `npm start`
Runs the app in development mode.

### `npm test`
Runs the test suite.

### `npm run build`
Builds the app for production.

### `npm run eject`
Removes the single build dependency from your project.
