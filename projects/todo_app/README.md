
# Todo App

This project is a simple Todo application that helps users manage their daily tasks. You can add, view, complete, and delete tasks in an intuitive interface.

## Features

- Add new todos
- Mark todos as completed
- Delete todos
- View all tasks in a list
- Responsive design for desktop and mobile

## How to Use

1. Enter a task in the input field and click "Add" to create a new todo.
2. Click on a todo to mark it as completed.
3. Click the delete button to remove a todo from the list.

## Project Structure

- `src/` — Source code for the todo logic and UI
- `public/` — Static assets
- `README.md` — Project documentation

## Getting Started

Clone the repository and open the project folder. No special setup is required if you use the provided HTML/JS/CSS files. For advanced usage or customization, refer to the source code and documentation.
